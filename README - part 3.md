# Tech Collective Website

This is the official website for **Tech Collective**, a platform offering affordable refurbished laptops, smartphones, and tablets to promote sustainability through technology reuse.

## Features
- **Dynamic Cart**: Users can add items to their cart and view the checkout page with a detailed order summary.
- **SEO Optimized**: Fully optimized for search engines with relevant keywords, meta tags, and alt text for images.
- **Interactive Features**: Includes a lightbox for images, interactive maps for location details, and a search feature to browse products.
- **User-Friendly Forms**: Contact forms with validation for user inquiries.

## Installation
To run this website locally:
1. Clone the repository: `git clone <repository_url>`
2. Open the `index.html` file in a browser.

## Technologies Used
- HTML5
- CSS3
- JavaScript (for interactivity and dynamic content)
- Google Maps API for interactive map integration
